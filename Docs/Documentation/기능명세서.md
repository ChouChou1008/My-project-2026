# 기능 명세서

2026-11-05 · 원본: [Claude Docs 기능 명세서](https://claude.ai/artifact/SbS2GwjtXnGsKUEQ1gJn3D)

## 개요

이 명세서는 「숲의 속삭임」 기획서(`Docs/Documentation/기획서.md`, 2026-10-15 초안)에서 구현할 기능을 뽑아 정리한 것이다. 데모 범위는 기획서 메모에 따라 **엘프 발견까지**로 잡고, 세계수와 엔딩은 이후 확장으로 둔다.

| 항목 | 내용 |
| --- | --- |
| 장르 | 채집 어드벤처 · 경영 시뮬레이션 · 미스터리 |
| 핵심 루프 | 낮 숲 채집 → 저녁 가공 → 밤 가게 판매 → 정산·업그레이드 |
| 핵심 축 | 하루 루프, 엘프 신뢰, 유적 해독 |
| 엔진 / 입력 | Unity 6 (URP, Windows), new Input System (`TechSpec.md` 기준) |
| 데모 범위 | 1막(채집꾼의 일상) ~ 엘프 발견 |
| 확장 범위 | 세계수, 지형 변화, 멀티 엔딩 |

기능 상세는 "무엇을, 어떤 조건에서" 해야 하는지만 정한다. 어떻게 구현할지는 개발하면서 직접 설계한다.

## 기능 상세

기능마다 조건, 동작, 예외를 적었다. 기획서에 수치가 없는 것은 "미정"으로 두고 마지막 섹션에 질문으로 모았다.

### F-01 플레이어 이동

- **설명**: 숲(낮)에서는 탐험, 마을(밤)에서는 마을·가게 사이를 이동한다.
- **입력**: 이동 키. new Input System의 `InputAction`으로 받는다(`TechSpec.md`).
- **동작**: 입력 방향으로 이동하고 캐릭터가 그 방향을 본다. 이동 속도에 맞춰 애니메이션이 바뀐다.
- **예외**: 가공·판매·대화 중에는 이동을 막을지 미정.

### F-02 상호작용

- **설명**: 하나의 상호작용 입력으로 장소에 따라 다른 행동을 한다.
- **조건**: 플레이어가 상호작용 대상 근처에 있을 때.
- **동작**: 숲 = 채집, 유적 조사 / 마을 = 가공, 판매, 대화.
- **예외**: 대상이 여러 개 겹치면 무엇을 고를지 미정.

### F-03 채집

- **설명**: 숲에서 산초·약초·버섯·희귀 식물을 캔다.
- **조건**: 낮, 채집물 근처, 가방에 빈칸 있음. 채집물에 따라 필요한 도구가 다를 수 있다(F-04).
- **동작**: 채집물이 가방에 들어가고, 숲에서는 사라지거나 채집된 상태가 된다.
- **예외**: 가방이 가득 찼으면 채집할 수 없고 알림을 보여 준다. 채집물이 다음 날 다시 자라는지는 미정.
- **특수 채집물**: 빛나는 산초를 캐면 숨겨진 통로가 열린다(F-12).

### F-04 채집 도구

- **설명**: 낫, 삽 같은 도구로 채집한다. 도구를 강화하면 더 귀한 재료를 캘 수 있다.
- **입력**: 도구 사용 키 (상호작용 키와 따로 둘지는 미정).
- **동작**: 현재 도구가 채집물에 맞으면 채집에 성공한다.
- **예외**: 도구가 맞지 않거나 등급이 낮으면 실패 안내를 보여 준다.

### F-05 가방(인벤토리)

- **설명**: 채집물을 담는다. 용량이 탐험 범위를 제한한다.
- **동작**: 채집하면 늘고, 가공·판매·엘프에게 주면 줄어든다. 업그레이드로 용량이 늘어난다.
- **미정**: 기본 용량, 같은 재료를 겹칠 수 있는지, 밤 재고(8장 UI)와 같은 공간인지.

### F-06 체력 / 낮 시간 제한

- **설명**: 낮 탐험에 끝을 만드는 자원. 기획서는 "체력(또는 해 지는 시간)"으로 아직 하나를 고르지 않았다.
- **동작**: 값이 다 떨어지면 낮이 끝나고 마을로 돌아간다(F-07).
- **예외**: 기다리지 않고 스스로 마을로 돌아갈 수 있는지, 다 떨어졌을 때 벌칙(채집물 손실 등)이 있는지 미정.

### F-07 하루 루프

- **설명**: 하루는 4단계를 차례로 돈다.
    1. 낮: 숲에서 채집
    2. 저녁: 마을에서 가공
    3. 밤: 가게에서 판매
    4. 정산: 업그레이드 후 다음 날 1단계로
- **조건**: 낮은 F-06이 끝날 때, 나머지는 플레이어가 끝내기를 고를 때 다음 단계로 넘어간다.
- **동작**: 단계가 바뀌면 장소, 조작 의미(F-02), UI(F-16), 색감 분위기가 함께 바뀐다.
- **예외**: 저녁과 밤을 다른 단계로 나눌지, 가공과 판매를 섞어서 할 수 있게 할지 미정.

### F-08 가공(요리·약재)

- **설명**: 채집물을 레시피대로 요리나 약재로 바꾼다.
- **조건**: 저녁, 조리·조제 도구 앞, 알고 있는 레시피, 재료가 충분함.
- **동작**: 재료를 쓰고 완성품을 재고에 더한다.
- **예외**: 재료가 모자라면 만들 수 없다. 미니게임을 넣을지 미정.

### F-09 가게 판매

- **설명**: 밤에 손님 주문을 받아 완성품을 팔고 돈과 평판을 얻는다.
- **동작**: 손님이 오고 주문을 낸다. 맞는 물건을 주면 돈과 평판이 오르고, 오늘 매출에 쌓인다.
- **예외**: 재고가 없거나 다른 물건을 주면 어떻게 되는지(평판 하락, 손님 이탈 등) 미정.

### F-10 정산·업그레이드

- **설명**: 하루를 마치며 번 돈을 보여 주고 업그레이드를 산다.
- **업그레이드 대상** (6장):
    - 채집꾼: 가방 용량, 체력, 채집 도구
    - 가게: 레시피, 주방 설비, 손님 수
- **예외**: 돈이 모자라면 살 수 없다. 평판이 업그레이드 조건이 되는지 미정.

### F-11 지역 개방

- **설명**: 숲은 깊이에 따라 층이 나뉘고, 조건을 채우면 다음 층이 열린다. 데모 지역은 아래 세 곳이다.

| 지역 | 열리는 조건 | 주요 채집물 |
| --- | --- | --- |
| 숲 가장자리 | 시작 | 일반 산초, 흔한 약초, 버섯 |
| 깊은 숲 | 1막 진행 (구체 조건 미정) | 희귀 산초, 발광 식물 |
| 엘프의 영역 | 2막 + 엘프 신뢰도 단계 | 엘프 약초, 마력 깃든 열매 |

- **예외**: 열리지 않은 지역으로 가려 하면 막고 이유를 알려 준다.

### F-12 이상 징후·발견 이벤트

- **설명**: 채집 중에 스토리 단서를 보여 주는 이벤트.
- **종류**: 시든 나무, 지도에 없던 길, 발광 식물, 바위의 문양, 숨겨진 통로.
- **동작**: 조건을 채우면 한 번 일어나고, 일어났다는 사실이 저장된다. 문양을 발견하면 알림을 띄운다(8장 UI).
- **핵심 이벤트**: 빛나는 산초 채집 → 땅 울림 → 통로 개방 → 석조 유적과 엘프 비문.
- **예외**: 이미 본 이벤트는 다시 일어나지 않는다.

### F-13 엘프 신뢰도

- **설명**: 엘프가 플레이어를 얼마나 믿는지 나타내는 값. 단계가 있다.
- **동작**: 부탁(F-14)을 완료하면 오른다. 단계가 오르면 새 지역, 엘프 상점, 엘프 레시피, 해독 단어 중 하나 이상이 열린다.
- **UI**: 언제나 보이는 신뢰도 게이지(F-16).
- **미정**: 단계 수, 단계별 보상, 신뢰도가 내려갈 수 있는지.

### F-14 엘프 부탁

- **설명**: 엘프가 특정 약초, 희귀 산초, 치료 약재를 부탁한다.
- **동작**: 요청한 물건을 건네면 부탁이 완료되고 신뢰도가 오른다.
- **핵심 선택**: 같은 재료를 마을에 팔지 엘프에게 줄지 플레이어가 고른다.
- **미정**: 부탁에 기한이 있는지, 한 번에 몇 개까지 받을 수 있는지.

### F-15 유적 해독·해독 노트

- **설명**: 처음에는 읽을 수 없는 비문을 문양 조각과 엘프 단어로 조금씩 해독한다.
- **동작**: 모은 문양과 단어는 해독 노트에 기록된다. 필요한 단서를 모두 모으면 비문이 풀리고 다음 목표가 열린다.
- **연결**: 유물을 마을 기록관에게 보여 주는 대화도 여기에 포함한다(3장 2막).
- **미정**: 데모에서 해독을 어디까지 보여 줄지, 퍼즐 형태.

### F-16 HUD / UI

| 장소 | 표시 항목 |
| --- | --- |
| 숲(낮) | 체력 또는 남은 낮 시간, 문양 발견 알림 |
| 마을(밤) | 재고, 오늘 매출, 평판, 손님 주문 |
| 공통 | 엘프 신뢰도 게이지, 해독 노트 |

- 값이 바뀌면 바로 화면에 반영되어야 한다.
- **2026-11-12 변경**: 숲 HUD에 가방 용량을 항상 보여 주지 않기로 했다. 가방은 B키로 열어서 확인한다(F-05).

### F-17 오프닝·튜토리얼 흐름

기획서 9장 순서대로 진행되며, 각 단계에서 기능 하나씩을 가르친다.

1. 숲 가장자리에서 산초 채집 → F-01, F-03
2. 시든 나무 발견 → F-12
3. 마을에서 가공·판매 → F-07, F-08, F-09
4. 다음 날 빛나는 산초 발견 → F-11
5. 통로 개방과 유적 → F-12
6. 기록관에게 유물 보여 주기 → F-15

### F-18 세계수·지형 변화·엔딩 (데모 제외)

- 세계수가 약해지면 지형이 바뀌고, 회복되면 숲 색이 살아난다.
- 엔딩은 정식 결말 하나에 해독 기록과 신뢰도에 따라 세부 내용이 달라진다.
- 데모 이후 기획이 확정되면 상세를 적는다.

## 미정 사항 및 생각해볼 질문

기획에서 먼저 정해야 할 것과 구현 전에 스스로 답해 볼 질문을 나눠 두었다. 답이 정해지면 체크하고 기능 상세에 반영한다.

**기획에서 정할 것**

- [ ] 낮 탐험을 제한하는 것은 체력인가, 해 지는 시간인가, 둘 다인가? (F-06)
- [ ] 데모의 끝은 엘프 마을 발견인가, 첫 신뢰도 단계 달성인가? 고대 유적(3막)과 해독은 어디까지 넣나? (F-11, F-15)
- [ ] 점프는 기획서 조작표에 없다. 점프가 필요한 지형이나 장치가 있나? (`Jump.cs`)
- [ ] 가방 기본 용량, 신뢰도 단계 수, 업그레이드 가격 같은 숫자는 누가 언제 정하나?
- [ ] 할 수 없는 행동을 했을 때(가방 가득, 재료 부족, 잠긴 지역) 알림은 어떤 모습인가?

**구현 전에 생각해볼 질문**

- 같은 상호작용 키가 채집에도, 판매에도, 대화에도 쓰인다. 플레이어 스크립트가 대상의 종류를 모두 알아야 할까?
- "지금이 낮인지 밤인지"를 묻는 스크립트는 몇 개일까? 단계가 바뀔 때 그 스크립트들은 어떻게 알게 될까?
- 산초 하나가 가방, 가공 재료, 판매 물건, 엘프 부탁에 모두 나온다. 아이템 정보는 한 곳에 둘까, 기능마다 둘까?
- 한 번 본 이벤트, 열린 지역, 신뢰도는 다음 날에도 기억해야 한다. 게임을 끄고 다시 켜도 남아야 할까?
- `PlayerMove.cs`는 이벤트 방식, `Jump.cs`는 `Update`에서 매 프레임 확인하는 방식이다. 두 방식은 무엇이 다르고, 지침에 맞추려면 어느 쪽을 고쳐야 할까?
