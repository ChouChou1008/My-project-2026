숲의 속삭임 3D 맵

1. ForestWhispers_Full 패키지의 Assets를 프로젝트에 넣습니다. (이미 넣었다면 생략)
2. 이 패키지의 Assets를 프로젝트에 넣습니다.
3. 위쪽 메뉴에서 Forest Whispers > Build 6 3D Maps를 누릅니다.
4. ForestWhispers_Map3D/Scenes에서 맵을 열고 Play를 누릅니다.

조작: WASD 이동, Shift 달리기, Space 점프, 마우스 오른쪽 버튼을 누른 채 둘러보기
머티리얼은 도구가 Built-in과 URP에 맞춰 자동으로 만듭니다.
